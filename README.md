# APEX MOTORWORKS — Cinematic 3D Automotive Experience V2

Визуально ориентированный демонстрационный сайт современного автосервиса **APEX MOTORWORKS** с непрерывной 7-сценной 3D-анимацией **Dodge Challenger SRT Hellcat** и его компрессорного двигателя **6.2L Supercharged HEMI V8**.

Построен на стеке **React 19 + TypeScript + Vite + Three.js + GSAP ScrollTrigger** и настроен для работы на GitHub Pages (`https://anemens3-oss.github.io/service4/`).

---

## 1. Семь непрерывных сцен 3D-анимации при прокрутке

Единый WebGL-контекст (`src/three/carScene.ts`) и единый контроллер `ScrollTrigger` управляют непрерывным переходом между 7 сценами (при прокрутке вниз и в обратном порядке при прокрутке вверх):

1. **Сцена 01 — Пролог (`01 / 07 · PROLOGUE`):**
   - Тёмная студия с объёмным светом, Dodge Challenger SRT Hellcat в глубине кадра, минималистичный заголовок `ENGINEERED TO PERFORM` и подсказка `SCROLL TO ENTER`.
2. **Сцена 02 — Движение автомобиля на зрителя (`02 / 07 · APPROACH`):**
   - Стартовый заголовок плавно растворяется; автомобиль физически движется вперёд навстречу камере (`carZ: -2.35m → +0.65m`), все 4 колеса синхронно вращаются вокруг своей оси (`θ = ΔZ / 0.387m`) и выравниваются по курсу.
3. **Сцена 03 — Пролёт сквозь решётку радиатора (`03 / 07 · GRILLE ENTRY`):**
   - Камера подлетает вплотную к передней маске Challenger и проходит сквозь геометрический проём решётки радиатора в освещённое подкапотное пространство.
4. **Сцена 04 — Сердце машины (`04 / 07 · HEART OF THE MACHINE`):**
   - Крупный план 28-компонентного двигателя **6.2L Supercharged HEMI V8**: синхронно вращаются 5 приводных шкивов, скользит свет по фрезерованному алюминию и чугунному блоку, нарастает механическая вибрация.
5. **Сцена 05 — Разрыв двигателя на детали (`05 / 07 · EXPLODED VIEW`):**
   - Управляемая инженерная декомпозиция (exploded view): корпус механического нагнетателя, ребристая крышка интеркулера, анодированные клапанные крышки, ГБЦ с пружинами клапанов, 8 кованых поршней с шатунами, коленвал, топливные рампы, выпускные коллекторы, шкивы и 260 металлических осколков расходятся по индивидуальным траекториям вокруг центральной оси.
6. **Сцена 06 — Сборка двигателя из осколков (`06 / 07 · REASSEMBLY`):**
   - Время обращается вспять: металлические частицы и все 28 узлов возвращаются по своим траекториям и с высокой точностью фиксируются обратно в единый работающий силовой агрегат.
7. **Сцена 07 — Возвращение наружу (`07 / 07 · EXTERIOR RETURN`):**
   - Камера вылетает из моторного отсека обратно через решётку радиатора в студию к выразительному внешнему ракурсу 3/4, после чего страница плавно переходит к информационным секциям автосервиса.

## 2. Структура разделов сайта (после 3D-сцены)

1. **`01 — Expertise` (`#expertise`):** 4 ключевых направления (Диагностика, Техническое обслуживание, Тормозная система, Обслуживание двигателя) с инженерными схемами и метрологическими допусками.
2. **`02 — Workshop` (`#workshop`):** 3 специализированных поста и 4 стандарта работы техцентра.
3. **`03 — Process` (`#process`):** 3 прозрачных этапа работы без онлайн-записи (`01 Осмотр`, `02 Согласование работ`, `03 Обслуживание`).
4. **`04 — Contact` (`#contact`):** Только прямой телефон с активной ссылкой `tel:` и адрес автосервиса (редактируются в `src/config/siteConfig.ts`). Все формы записи и модальные окна полностью удалены.

## 3. Локальный запуск и сборка для GitHub Pages

```bash
# Установка зависимостей
npm install

# Запуск dev-сервера (порт 3000)
npm run dev

# Проверка типов TypeScript
npm run lint

# Production-сборка (обновляет dist/ и docs/ с относительными путями base: './')
npm run build
```
